# CollegeBot - Rule Based College FAQ Chatbot

## AI & ML Internship - Project 2 Task 1

CollegeBot is a Python-based rule-driven chatbot developed as part of an Artificial Intelligence and Machine Learning Internship.

The chatbot provides answers to common college-related queries such as admissions, courses, fees, hostel facilities, and placements.

---

## Features

- Rule-Based Conversation System
- Text Preprocessing
- Pattern Matching
- Regex-Based Query Detection
- Random Response Generation
- Interactive Chat Interface

---

## Technologies Used

- Python
- Regular Expressions (Regex)
- Lists and Dictionaries
- Jupyter Notebook
- VS Code

---

## Categories Supported

The chatbot can answer questions related to:

- Admission Process
- Fee Structure
- Courses Offered
- Hostel Facilities
- Placement Information
- General Greetings
